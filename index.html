01 / About

Most automation projects break because of the plumbing, not the model. I get the plumbing right first.

I come from backend work. Django, DRF, FastAPI, PostgreSQL, and the API design that holds a product together. That is what makes the AI part reliable. Clean request models, safe writes, proper error handling, and responses fast enough that someone on a live phone call never hears an awkward pause.

On top of that I build search and retrieval systems with Pinecone and LangChain, voice agents on Retell, and n8n workflows connected to CRMs like GoHighLevel and HubSpot. Everything ships in Docker with the deployment sorted out before the demo, because a workflow nobody can run is not really automation.
